# Orion Course Creator 🚀

Orion is a world-class, AI-driven course architect designed to transform educational concepts into professional, multi-format learning assets. From interactive slide decks and studio-quality audiobooks to beautifully formatted ebooks, Orion handles the heavy lifting of instructional design.

## 🌟 Key Capabilities

### 1. AI Slide Orchestration
Orion integrates with the Gamma API to generate professional slide decks. Unlike generic generators, Orion intelligently selects themes and design layouts based on the **Course Style** (e.g., Storytelling, Academic, Scenario-based) to ensure your visuals match your message.

### 2. Narrative Audiobooks
Powered by ElevenLabs, Orion generates high-fidelity audio courses. Every module features character-driven narration and comes with a perfectly aligned transcript, creating an immersive "voicebook" experience.

### 3. Polished Ebook Publishing
Our advanced narrative engine transforms fragmented module content into a smooth, human-readable book. Ebooks are generated as PDFs with:
- **Natural Chapter Flow**: No more dry bullet points; everything is written in a rich narrative style.
- **Automated Diagrams**: Integrated Mermaid.js support for professional flowcharts and architectures.
- **Engaging Introductions**: AI-crafted hooks for every section.

### 4. Structured PPTX Exports
Download your slide decks in professional PowerPoint format. Orion enforces a specialized **Split-Screen Layout**:
- **Left Side**: Visual slide content and bullets.
- **Right Side**: Full voiceover script for the presenter.

### 5. Procedural Wizard Guidance
The "Orion Guidance" interface provides a step-by-step wizard for course creation. It offers localized, procedural instructions at every stage—from audience definition to module scaling—ensuring high-quality output every time.

--- 

## 🛠 How It Works

### Step 1: Deep Configuration
Creators input their course topic, target audience, and instructional level. Crucially, they select a **Course Style**, which directs the AI's tone, character personas, and visual aesthetics across all generated materials.

### Step 2: Curriculum Architecture
Orion's AI (GPT-4) builds a logical, 10-15 minute instructional curriculum. It ensures that sub-topics follow a natural progression (e.g., Fundamentals → Strategy → Execution) without content overlap.

### Step 3: Asset Synthesis
Once the curriculum is set, creators can trigger the generation of specialized assets:
- **Slides**: High-impact visual decks.
- **Voice Scripts**: Detailed narration for video production.
- **Audiobooks**: Export-ready MP3s with transcripts.
- **Ebooks**: Narrative-driven PDFs for reading.

### Step 4: Review & Export
Assets are managed in a centralized dashboard where creators can refine content, regenerate modules, or download final files for distribution.
